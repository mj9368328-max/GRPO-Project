## 1. Objective
The objective is to demonstrate a lightweight reinforcement-learning fine-tuning workflow for mathematical reasoning using Group Relative Policy Optimization (GRPO), Unsloth, and a rule-based reward function on a Google Colab GPU.

## 2. Tools and model
- Google Colab with a T4 GPU (subject to availability)
- Python, PyTorch, Hugging Face Datasets, TRL, and Unsloth
- Base model: `Qwen/Qwen2.5-0.5B-Instruct`
- Parameter-efficient fine-tuning: LoRA adapters with 4-bit model loading
- Dataset: a small subset of GSM8K math word problems

## 3. Methodology
1. Load a compact instruction-following model in 4-bit mode.
2. Prepare math questions with a prompt requiring a short explanation and a final answer marked `####`.
3. Define reward functions:
   - **Correctness reward:** positive reward for matching the reference numeric answer and a penalty for incorrect answers.
   - **Format reward:** small positive reward for using the required final-answer marker.
   - **Conciseness reward:** small reward for responses within a reasonable word range.
4. Run a short GRPO training loop with multiple sampled completions per prompt.
5. Plot logged reward values and inspect generated responses.
